# ことば辞典 v1.0

アカウントごとに自分の辞典データを管理するバージョンです。

## 主な変更

- メールアドレス＋パスワードの新規登録
- ログイン
- ログアウト
- パスワード再設定メール
- アカウントごとのクラウド保存
- ユーザーごとのデータ分離
- RLSによるアクセス制御
- 旧localStorageデータのアカウント移行
- アカウント単位のバックアップ・復元

## 使用技術

- HTML
- CSS
- JavaScript
- Supabase Auth
- Supabase Postgres
- Row Level Security

## セキュリティ

ブラウザにはSupabaseのPublishable keyだけを置きます。

Secret key / service_role keyはブラウザへ公開しません。

データベースでは `user_id` と `auth.uid()` をRLSで照合します。

## セットアップ

詳しくは `SETUP.md` を確認してください。

## v1.1 類似語・あいまい検索
- 入力ミスや一部だけの語句でも、言葉・読み・意味・例文・タグなどから候補を探します。
- ひらがな／カタカナ、全角／半角の違いを吸収して検索します。
- 「あいまい検索・類似語も含める」をオフにすると、あいまい検索を無効にできます。
- 登録済みの関連語・共通タグ・同じカテゴリーを手がかりに、近い候補も表示します。

## v1.2 途中保存機能
- 入力中の内容をブラウザー内に自動保存します。
- 「途中保存」ボタンで明示的に保存できます。
- 「言葉を追加」を再度開くと、前回の途中保存を復元します。
- 途中保存データはログインユーザーごとに分けて、この端末のブラウザーに保存します。
- 正式に保存すると、その入力フォームの途中保存データは削除されます。
- 途中保存は同じブラウザー・端末内での復元用であり、Supabaseへは送信されません。
